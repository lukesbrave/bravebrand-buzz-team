# BraveBrand Team

Recruit your AI team to build and grow a Digital Home you own.

## Install in Buzz One Beta

1. Open **Settings → Plugins → Manage plugins → Add**.
2. Paste **https://github.com/lukesbrave/bravebrand-buzz-team**.
3. Leave **Branch or tag blank** and click **Find**.
4. Select **BraveBrand Team** in **dist**, review access, then install/enable.
5. Open **BraveBrand Team** and enter your access link from the Skool classroom.

Connect Goose, Claude or Codex in **Settings → Agent setup** before recruiting. With Goose, hires use the provider and model you set in Buzz. Standard and Premium members use the
same plugin. Membership access links are provided separately in the classroom.

## Already installed?

Open the plugin's details in Settings, choose **Check for updates**, then
**Update** and confirm the review. Do not delete the plugin or rehire employees.

This updates the recruiting page, including its branding and Premium access
screen. It does not replace existing employees, chats or training.
See [installation and update instructions](releases/GITHUB-INSTALL.md).

The sidebar uses the BB monogram; the plugin listing uses the BRAVE wordmark.
